# ARNA: лендинг және браузерлік демо (1-кезең)

Нақты уақыттағы дауыстық аударма платформасының жарнамалық беті және сценарийлі демо.
Дизайн бағыты «Бір сызық»: жіңішке алтын дыбыс толқыны hero-дан бастап бүкіл бетті байланыстырады (`docs/design-system.md`).
Next.js 16 (статикалық экспорт), TypeScript, Tailwind CSS 4, Motion. Backend пен дерекқор жоқ.

- Он тіл: `ru kk en zh uz ky ko ja hi ar` (араб тілінде толық RTL).
- Жарық/қараңғы тақырып (жүйе баптауын автоматты таниды).
- Мобильде: қатып тұратын header, оң жақта ☰ (ашылғанда ✕), тіл ауыстырғыш ☰-тің сол жағында, көлденең скролл/созылу жоқ.
- Сценарийлі демо: тіл таңдау, дауыс растау, жазу эффектісімен тыңдау, аудио/субтитр ауыстырғышы, фон режимі, автоконспект.
- Пилотқа қатысу формасы: дерекқорсыз (WhatsApp хабарлама жобасы немесе форма коннекторы).
- Оң жақ астында WhatsApp плавающий түймесі (+7 747 167 3817).

## Жылдам бастау

```bash
npm install
npm run dev          # http://localhost:3000  (алдымен тіл тізілімін жаңартады)
npm run build        # статикалық сайт: apps/web/out
npx serve apps/web/out
```

Node 20.9+ қажет. Қаріптер мен суреттер репозиторийде дайын, қосымша жүктеу керек емес.

## Құрылым (ТЗ 7-бөлім)

```
apps/web/                 Next.js қосымшасы (лендинг + демо)
  src/app/[lang]/         әр тіл үшін бет: /ru/ /kk/ /en/ ...
  src/app/(redirect)/     "/" : сақталған немесе браузер тіліне бағыттайды
  src/components/         Header, Hero, WaveCanvas, ModuleTabs, LangStrands, PhoneDemo, Cases, Pricing, PilotForm, ...
  public/brand/           жаңа логотип пен иконкалар (`npm run brand` жасайды), қараңыз «Логотип және ұран»
  public/images/          суреттер (docs/photo-credits.md)
  public/fonts/           өзіміз хосттайтын қаріптер (тілге қарай бөлінген)
packages/i18n/            ru.json kk.json en.json ... ar.json (әр тіл бөлек файл)
content/demo-script.json  демоның үлгі транскрипті (қазақша түпнұсқа + 10 тіл) және автоконспект
scripts/                  құрал-саймандар (төменде)
docs/                     құжаттар
```

## Жаңа тіл қосу (кодты өзгертпей)

1. `packages/i18n/en.json` файлын `xx.json` етіп көшіріп, аударыңыз. `_meta` блогын толтырыңыз
   (`code`, `nativeName`, `dir`: `ltr`/`rtl`, `htmlLang`, `ogLocale`, `welcome`, `font`).
   `font`: `latin`, `cyrillic`, `cjk-sc`, `cjk-jp`, `cjk-kr`, `devanagari`, `arabic`.
2. `content/demo-script.json` ішіне `xx` кілтін қосыңыз (5 жол + 3 тармақ автоконспект).
3. `npm run fonts` (қаріптерді қайта құрады, интернет қажет), `npm run i18n:check`, `npm run build`.

`npm run i18n:check` барлық тілдің құрылымын `en.json`-мен салыстырады, бос жолдарды, ұзын сызықшаны (em-dash) және
демо сценарийінің толықтығын тексереді. Қате болса build тоқтайды.

## Мәтінді өзгерткенде

Мәтін `packages/i18n/*.json` ішінде. Қытай, жапон, корей, хинди, араб қаріптері сайтта қолданылатын таңбаларға ғана
қысқартылған (бет жылдам жүктелуі үшін). Мәтінді өзгертсеңіз: `npm run fonts` қайта іске қосыңыз.
Латын және кирилл қаріптері (Onest, Commissioner) толық, оларға бұл қажет емес.

## Демо дауысы (алдын ала жазылған аудио)

Демо `speechSynthesis` емес, дайын MP3 ойнатады: `apps/web/public/audio/demo/<тіл>/<1-5>.mp3`. Файлдардың ұзақтығы мен көлемі
`apps/web/src/lib/demo-audio.json` ішінде (аударма мәтіні сол ұзақтықта «теріледі», сондықтан дауыс пен мәтін бірге аяқталады).
Файл жоқ немесе жүктелмесе, мәтін бәрібір көрсетіледі. Тіл таңдалғанда 5 файл алдын ала жүктеледі, фон режимі мен Media Session
(құлыптаулы экран, құлаққап) жұмыс істейді, субтитр режимінде (аудио өшірулі) дауыс болмайды.

Басқа жерде жасалған файлдарды (`<тіл>-<n>.mp3`) `content/audio-source/` ішіне салып, `npm run demo:audio -- import` іске қосыңыз
(ffmpeg керек, кілт керек емес): файлдар 96 kbps моно етіп қайта кодталып, `<тіл>/<n>.mp3` қалпына түседі, manifest жаңарады.
`content/audio-source/` git-ке түспейді.

Қайта жазу үшін `.env.local` (git-ке түспейді) ішіне `ELEVENLABS_API_KEY=...` қойыңыз, кілтті кодқа, логқа немесе commit-ке жазбаңыз:

```bash
npm run demo:audio -- all --dry-run --model eleven_v4 --voice <voice_id>   # неше таңба / несие кететінін көрсетеді
npm run demo:audio -- sample --model eleven_v4 --voices <id1>,<id2>,<id3>  # қазақша бірінші сөйлем, тыңдап таңдау үшін
npm run demo:audio -- all --model eleven_v4 --voice <voice_id>             # барлық 10 тіл, 96 kbps моно, жалпы көлем 3 МБ-тан аз
```

Қазақ, қырғыз, өзбек тілдерін `eleven_v4` және `eleven_v3` қолдайды (`multilingual_v2` және `flash/turbo v2.5` қолдамайды).

## Логотип және ұран

Логотип: `content/brand/arna-logo-source.png` (алтын 3D дыбыс толқыны, ол «ARNA» деп оқылады). `npm run brand` оны тазалайды (ақ жиек,
шашыраңқы нүктелер), қияды және `apps/web/public/brand/` ішіне 480/960 px (WebP және PNG), favicon, apple-touch, PWA және maskable
иконкаларын, `apps/web/public/og.png` суретін жазады. Барлық жол мен өлшем бір модульде: `apps/web/src/lib/brand.ts` (дизайнер SVG берсе,
ауысатын жер осы және скрипт). Логотиптің қасына «ARNA» жазуын қоспаңыз.

Ұран (`packages/i18n/slogan.json`, әр сайт тілінде): логотиптің астында `<p>` ретінде (`BrandLockup`: hero, footer), хедерде, телефонда мен
демо бетінде тек логотип. Ұранның өзін ауыстыру: `slogan.json` өзгертіп, `npm run i18n:check` және `npm run qa:brand` жүргізіңіз.
Жаңа тіл қоссаңыз, `slogan.json` ішіне сол тілдің ұранын қосыңыз, әйтпесе `i18n:check` тоқтатады.

## Серіктестік сілтемелер

Серіктестерге мына сілтеме беріледі: `https://arnavoice.com/?ref=КОД` (КОД: 4-20 латын әрпі не саны). Скриптсіз де жұмыс істейтін
қосалқы сілтеме: `https://app.arnavoice.com/ref/КОД`.

Сайт мынаны істейді:

- `/` және `/demo/` бетінен тіл бетіне бағыттағанда `?ref=КОД` пен `#` сақталады (`RedirectView.tsx`).
- Әр беттің `<head>` ішіндегі кішкентай inline скрипт (`apps/web/src/lib/referral.ts`) `ref` мәнін оқып,
  `POST https://app.arnavoice.com/api/referral/click` (`{code, page}`) жібереді. Код тек `A-Z`, `0-9` және 4-20 таңба болса ғана
  жіберіледі, бір сессияда бір рет (`sessionStorage`, `arna-ref-sent`), қате сайтты бұзбайды. `page` өрісінде тек жол жіберіледі
  (`NEXT_PUBLIC_BASE_PATH` кесіледі).
- `arna_ref` (90 күн) және `arna_did` cookie-лерін тек қызметтің өзі (`app.arnavoice.com`) қояды, сайт cookie қоймайды. Аналитика,
  пиксель, сыртқы кітапхана жоқ. Тіркелген адам серіктеске автоматты бекітіледі, сондықтан Live сілтемесіне `?ref=` қосудың қажеті жоқ.
- Footer-дегі «Құпиялылық» сілтемесі `https://app.arnavoice.com/privacy/` бетіне апарады (мәтін `footer.privacy`, 10 тілде).
- Қызмет мекенжайы `NEXT_PUBLIC_APP_URL` (әдепкі `https://app.arnavoice.com`): API, Live және Құпиялылық сілтемелері соған құралады.

Тексеру: `https://arnavoice.com/?ref=<код>` ашып, браузердің Network қойындысында `referral/click` сұрауын (200, `Set-Cookie: arna_ref`)
көріңіз. Бір сессияда қайталанбайды; қайта тексеру үшін консольде `sessionStorage.removeItem("arna-ref-sent")`. Сервер CORS-ты тек
`arnavoice.com` және `app.arnavoice.com` үшін береді, сондықтан localhost-та нақты сұрау өтпейді. Жергілікті тексеру: `npm run qa:referral`
(Puppeteer сұранысты ұстап, жалған жауап береді, нақты API-ге ештеңе жіберілмейді).

## Форма: лид жинау

`apps/web/.env.local` (немесе Vercel Environment Variables):

```
NEXT_PUBLIC_LEAD_ENDPOINT=https://...   # Formspree / Web3Forms / Apps Script / webhook (JSON POST)
NEXT_PUBLIC_SITE_URL=https://your-domain.kz
```

- Коннектор көрсетілсе: форма деректерді сонда жібереді, қолданушыға "жіберілді" хабары шығады.
- Көрсетілмесе (немесе коннектор жауап бермесе): WhatsApp-та дайын хабарлама ашылады (+7 747 167 3817), қолданушы
  "Жіберу" батырмасын басады. Бұл жағдайда сайт "жіберілді" демейді, "дайын" дейді (шындыққа сай).
- Соңғы өтінім браузердің `localStorage` ішінде де сақталады (`arna-last-lead`), дерекқор құрылмайды.

## GitHub Pages (https://minaikhansaltanat-prog.github.io/arna/)

Репозиторийде `.github/workflows/pages.yml` бар: әр `main` push-тан кейін сайтты жинап, Pages-ке жариялайды.

**Бір реттік баптау (GitHub-та):** репозиторий **Settings > Pages > Build and deployment > Source: GitHub Actions**.
Әдепкіде "Deploy from a branch" тұрса, GitHub сайтты емес, `README.md` файлын көрсетеді.
Баптаудан кейін **Actions** бетінде "Deploy to GitHub Pages" жұмысын **Re-run** басыңыз (немесе кез келген push жасаңыз).

Pages сайты `/arna/` ішкі жолында тұрады, сондықтан жинау кезінде `NEXT_PUBLIC_BASE_PATH=/arna` беріледі (workflow өздігінен береді).
Форма коннекторын қосу үшін: **Settings > Secrets and variables > Actions > Variables** ішінде `NEXT_PUBLIC_LEAD_ENDPOINT`.

Жеткізу (өз домені): `NEXT_PUBLIC_SITE_URL=https://arnavoice.com NEXT_PUBLIC_ROOT_VIEW=site npm run build`, нәтижесі `apps/web/out`.

Жергілікті тексеру (Pages-пен бірдей): PowerShell-де
`$env:NEXT_PUBLIC_BASE_PATH='/arna'; npm run build; $env:BASE_PATH='/arna'; node ../serve.mjs` және `http://localhost:3000/arna/`.

## Өз серверіне (Ubuntu 24.04 VPS, nginx)

Серверде root ретінде бір команда (қайта іске қосса, соңғы кодты алып, қайта жинайды):

```bash
curl -fsSL https://raw.githubusercontent.com/minaikhansaltanat-prog/arna/main/deploy/setup-server.sh | DOMAIN=arna.kz EMAIL=you@mail.kz bash
```

`DOMAIN` пен `EMAIL` міндетті емес (екеуі бар болса HTTPS қосылады). Код `/opt/arna`, сайт `/var/www/arna` ішінде.

### Демо-қосымша (`/<тіл>/demo/`, `/demo/`)

Жеке мобильді-бірінші бет: телефонда экранды толық алады (қосымша сияқты), компьютерде ортада телефон рамасы және QR-код тұрады. Алдымен тіл таңдалады, содан кейін «Демонстрация на примере сценария» сценарийді іске қосады (спикер сөзі → аударма мәтіні мен дауысы). Дауыс браузердің `speechSynthesis` арқылы жергілікті шығады (API жоқ; құрылғыда сәйкес дауыс болмаса, тек мәтін).

Серверде `/` әдепкіде демоға апарады (`NEXT_PUBLIC_ROOT_VIEW=demo`); лендинг `/<тіл>/` мекенжайында. Түбірді лендингке қайтару үшін `ROOT_VIEW=site` беріңіз.

## Vercel-ге деплой

1. Репозиторийді GitHub-қа салыңыз (бұл репозиторий).
2. Vercel: **Add New > Project**, репозиторийді таңдаңыз. **Root Directory** өзгертпеңіз (репозиторий түбірі).
   Баптаулар `vercel.json` ішінде дайын: `npm install`, `npm run build`, `apps/web/out`.
3. Қаласаңыз Environment Variables қосыңыз (жоғарыда). **Deploy**.
4. Өз доменіңізді **Settings > Domains** ішінде жалғаңыз, `NEXT_PUBLIC_SITE_URL` мәнін соған қойыңыз.

Сайттың өзі cookie қоймайды және деректерді өз серверінде жинамайды (дерекқор жоқ). Серіктестік сілтемемен (`?ref=`) келгенде ғана
`app.arnavoice.com` қызметіне басу туралы хабар кетеді, ал `arna_ref`, `arna_did` cookie-лерін және IP хэшін сол қызмет жазады: толық
мәтін `https://app.arnavoice.com/privacy/` бетінде, footer-де «Құпиялылық» сілтемесі бар (жоғарыдағы «Серіктестік сілтемелер»).
ps.kz бұл кезеңде қажет емес (ТЗ 2.2).
