# Жаңа логотип және ұран: жоспар мен ескертпелер

Бұл жұмыс түнде, адамсыз жүргізілді: күмәнді жерде ең қауіпсіз, оңай өзгертілетін нұсқа таңдалды, олар төмендегі «Таңертеңгі сұрақтар» бөлімінде.

## Жоспар

1. Дереккөз `arna-logo.png` (1573x1000, ішінде мөлдір бос орын мен ақ жиек бар) `content/brand/arna-logo-source.png` болып көшірілді. `npm run brand` (`scripts/build-brand.mjs`, sharp) оны тазалайды: шашыраңқы нүктелерді алады, жиектегі ақ нимбті ішкі түспен ауыстырады, бос орынды қияды. Одан 480 және 960 px (WebP және PNG), favicon, apple-touch, PWA және maskable иконкалары мен OG-сурет жасалады.
2. Файл жолдары мен өлшемдері бір модульде: `apps/web/src/lib/brand.ts` (өлшемдер `brand.manifest.json` ішінде, скрипт жазады). Дизайнер SVG берсе, ауысатын жер осы.
3. Ұран: `packages/i18n/slogan.json` (10 сайт тілі және `tr`), `getSlogan(lang)` арқылы оқылады, `npm run i18n:check` барлық тілде барын тексереді. Ұран суретке жазылмайды, `<p>` мәтіні (H-тег емес).
4. Бір компонент `BrandLockup` (логотип және астында ұран): нұсқалары `hero`, `footer`, `compact` (ұрансыз, хедер, телефон, демо беті). Өлшемі логотип еніне байланысты: ұран қарпі шамамен 5,5% (кемі 13 px), аралық 4,5%, ұран ені 55-70% ішінде болуға тырысады.
5. Орындар: хедер, hero, footer, `/<тіл>/demo/` беті, телефон бейнесінің шапкасы, тіл жіптерінің қақпасы, favicon, PWA, OG, JSON-LD, Media Session суреті, 404 және қате беті. Ескі эмблема мен жеке «ARNA» жазуы алынып, ескі файлдар өшіріледі.
6. Preloader репода жоқ: жаңасын жасамадым (себебі төменде).
7. Тексеру: `scripts/qa-brand.mjs` (ұран барлық тілде, өлшем, контраст, CLS, ескі эмблема жоқ), бұрынғы `build`, `lint`, `qa`, `qa:demo`, `qa:a11y`, скриншоттар (360 және 1440 px, ашық және қараңғы, араб, қытай, қазақ).
8. Әр қадамнан кейін commit және push. Соңында release zip (SHA-256) және `deploy/brand-slogan-release.md`.
